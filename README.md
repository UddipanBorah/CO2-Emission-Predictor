# CO2 Car Emission Analyzer 🚗💨

### Overview
A predictive machine learning pipeline and interactive Streamlit application designed to accurately estimate vehicle CO2 emissions based on varying automobile features.

### Technical Highlights
* Conducted exploratory data analysis (EDA) and data preprocessing on a comprehensive dataset of ~10,060 records.
* Engineered 68 distinct features utilizing one-hot encoding techniques to optimize the dataset for robust model training.
* Implemented and trained multiple regression algorithms, including Linear Regression, Decision Trees, and Random Forests.
* Evaluated and compared model performance using statistical metrics such as R², RMSE, and MAE to ensure high predictive reliability.

### Tech Stack
* **Language:** Python
* **Machine Learning:** Scikit-Learn
* **Data Processing & Visualization:** Pandas, NumPy, Seaborn, Matplotlib
* **Web Framework:** Streamlit
